# Structs

- Properties that are related such as suit and value.
- Values can be of different type.
- Keys don't support indexing.
- A thing with lot of different properties.
- Value type!
- Need to know all the different fields at compile time.
- Closed set of keys.

# Maps

- Keys of same type and values of same type.
- Collection of related properties.
- Keys are indexed by which we can iterate over.
- Reference type!
- Do not need to know all the keys at compile time.
